Mac系统SublimeText快捷键速查表

约 364 字大约 1 分钟

手册工具

2026-03-31

基础操作

功能快捷键
新建文件⌘ + N
打开文件⌘ + O
保存文件⌘ + S
另存为⌘ + Shift + S
关闭文件⌘ + W
退出应用⌘ + Q

编辑操作

功能快捷键
撤销⌘ + Z
重做⌘ + Shift + Z
剪切⌘ + X
复制⌘ + C
粘贴⌘ + V
全选⌘ + A
删除行⌘ + Shift + K
行上移⌘ + Ctrl + ↑
行下移⌘ + Ctrl + ↓

光标操作

功能快捷键
行首Home 或 ⌘ + ←
行尾End 或 ⌘ + →
文档开头⌘ + ↑
文档结尾⌘ + ↓
词首⌥ + ←
词尾⌥ + →
选择到行首⇧ + Home
选择到行尾⇧ + End

多光标操作

功能快捷键
添加光标⌘ + 鼠标点击
选择相同文本⌘ + D
选择所有相同文本⌘ + Ctrl + G
行尾添加光标⌘ + ⇧ + L
列选择⌥ + 鼠标拖拽

查找替换

功能快捷键
查找⌘ + F
查找下一个⌘ + G
查找上一个⌘ + Shift + G
替换⌘ + H
全局查找⌘ + ⇧ + F

导航

功能快捷键
跳转到行⌘ + G
文件切换⌘ + P
符号跳转⌘ + R
侧边栏切换⌘ + K, ⌘ + B

代码编辑

功能快捷键
代码折叠⌘ + ⌥ + [
代码展开⌘ + ⌥ + ]
折叠所有⌘ + ⌥ + ⇧ + [
展开所有⌘ + ⌥ + ⇧ + ]
注释行⌘ + /
块注释⌥ + ⌘ + /

窗口管理

功能快捷键
新建窗口⌘ + ⇧ + N
关闭窗口⌘ + ⇧ + W
分屏⌘ + ⌥ + 1-4
切换窗格⌘ + ⌥ + ←/→

命令面板

功能快捷键
命令面板⇧ + ⌘ + P
快速打开⌘ + P
构建⌘ + B
构建并运行⌘ + Shift + B

提示：⌘ = Command键，⌥ = Option/Alt键，⇧ = Shift键，⌃ = Control键
