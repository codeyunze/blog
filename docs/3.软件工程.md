## 四、第一阶段：现在 → 2026.6（基础打底）

### 1）英语二（每天 1h）

- 单词：红宝书 / 恋练有词 每天 50 新词 + 复习 100
- 语法：田静（全程零基础友好）
- 长难句：每日一句 **只打基础，不做真题**

### 2）数学二（每天 1.5h，最拉分）

- 高数：武忠祥
- 线代：李永乐 用书：
- 李永乐复习全书（数二）
- 660 题 目标：**6 月前过完一遍基础**

### 3）873 C 语言（每周 2 次，每次 1h）

只做 3 件事：

1. 过一遍谭浩强第 1–10 章（重点）
2. 手写基础语法：变量、判断、循环、数组、函数
3. 做课后习题 **不用深，保持手感**

### 4）政治：完全不学

## 八、873 C 语言极简必背重点（只考这些）

1. 数据类型、运算、表达式
2. 三大结构：顺序、选择（if/switch）、循环（for/while）
3. 数组（一维、二维）
4. 函数、递归
5. 指针（超级重点）
6. 结构体
7. 文件操作
8. 宏定义（近年新增）

**不考数据结构、不考算法、不考 C++、不考 408！** **只考纯 C 语法！**
